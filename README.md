# Kargo Etiket Programı

Kargo etiketi hazırlama ve yazdırma programı (Windows).

## Özellikler
- Gönderen ve alıcı kayıtları (ekle, düzenle, sil)
- Kargo firması seçimi (logolu): Yurtiçi, Aras, Sürat, PTT, HepsiJET, Trendyol, Kolay Gelsin, CargoX, DHL, FedEx, UPS
- Anlaşma kodu ve ödeme tipi (Ü.A. / P.Ö.)
- "Dikkat Kırılır" işareti
- Çıktı boyutu: 70 mm termal, A5, A4
- Canlı önizleme, açık / koyu tema

## Kullanım
`Kargo-Etiket-Programi.exe`'yi çalıştırın. Kurulum gerekmez (.NET Framework 4.8, Windows 10/11'de hazır gelir).
Kayıtlar exe'nin yanındaki `Kargo-Etiket-Veri.xml` dosyasında tutulur.

## Derleme
Linux/Mono: `./build.sh`

Hazırlayan: Önsel Özden
